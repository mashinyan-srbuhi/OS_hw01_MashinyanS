Task4: Pointers to Pointers

Declares an integer num = 10 and a pointer p that points to num
Declares a double pointer p2 that points to p (i.e. p2 stores the address of p, which  itself stores the address of num).
Prints the value of num using the pointer (our well-known *p).
Prints the value of num using the double pointer, **p2, which accesses the value stored at the address of p2, which is the address stored in p, and then accesses the value stored at that address, which is the value of num.
